## Ограничения, зафиксированные навсегда

1. Платформа не эмулирует поведение пользователей в поисковых системах и не
   накручивает поведенческие факторы. Позиции снимаются только через официальные API.
2. Краулинг и e2e-сценарии выполняются только по доменам с подтверждённым владением.
3. Соблюдаются robots.txt, лимиты запросов и условия использования внешних API.
